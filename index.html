Care hub orientation · only when opened from the widget

AndroidIn every option the page opens with Care hub underneath (TaskStackBuilder, Care hub as parent): the Care hub tab is selected and Back goes to Care hub, so members see where the page lives without being told.

Dropped: not possible on Android widgets

Content peek: widgets have no fade masks or snap-scrolling, so the half-visible next page would land at random scroll positions.

Nudge animation: widgets can't run custom animations. Auto-advance is the closest supported way to show motion.
